# Shared methodology

This directory defines the default experimental rules for new MRS studies.

- [`experimental-protocol.md`](experimental-protocol.md) — freezing, epochs, comparison arms, and evaluation order.
- [`metrics.md`](metrics.md) — metric families and comparison rules.
- [`agent-evaluation.md`](agent-evaluation.md) — controlled machine-maintenance experiments.
- [`evidence-and-claims.md`](evidence-and-claims.md) — evidence states and promotion boundaries.
- [`reproducibility.md`](reproducibility.md) — environment, seed, hash, and rerun requirements.
- [`migration.md`](migration.md) — moving historical case studies out of the standards repository.

Study-local methodology may be stricter. Any material deviation from these defaults should be explicit and versioned.
